# ExamTimeDown · 开发计划

## 一、技术选型与版本

| 项 | 选型 | 说明 |
|---|---|---|
| 语言/框架 | Kotlin 2.2.20 + Compose Multiplatform 1.9.3 | 与本地 pgprint 一致，已跑通 |
| 构建 | Gradle 8.14.3（腾讯云镜像）+ JDK 21 toolchain | 系统仅 JDK 11，foojay 自动下载 21 |
| KMP 目标 | 仅 `jvm()` | commonMain 放纯 Kotlin 业务逻辑 |

| 持久化 | kotlinx-serialization-json + JSON 文件 | 写 `%APPDATA%/ExamTimeDown/` |
| 异步 | kotlinx-coroutines 1.10.2（含 swing 扩展） | |
| 平台能力 | JNA 5.17.1（鼠标穿透 / 注册表自启，仅 Windows） | mac 降级忽略 |

> 不设 `skiko.renderApi=SOFTWARE`（透明置顶挂件需 GPU 渲染）。

## 二、目标形态

- **挂件窗口**：无边框、透明背景、置顶、可拖动、可锁定、可鼠标穿透，常驻桌面显示倒计时
- **管理窗口**：普通窗口，做增删改查
- **系统托盘**：显示/隐藏挂件、打开管理、退出

## 三、倒计时准确性五条铁律

1. **绝不递减累加**：每帧用 `目标时刻 - 当前时刻` 重算
2. **调度用单调时钟、取值用墙钟**：`delay()` 单调时钟，tick 用 `Instant.now()`
3. **秒边界对齐**：`delay(1000 - nowMs % 1000)`
4. **单一心跳源**：全应用共享 `SecondTicker`
5. **存墙上时间**（LocalDateTime + ZoneId），不存纯 epoch

## 四、数据模型

`countdowns.json`：
```json
{
  "version": 1,
  "items": [{
    "id": "uuid",
    "title": "期末考试",
    "note": "高数",
    "targetLocal": "2027-06-07T09:00:00",
    "zoneId": "Asia/Shanghai",
    "colorKey": "BLUE",
    "createdAt": "2026-11-02T10:00:00Z",
    "archived": false,
    "visibleOnWidget": true,
    "reminderOffsets": [86400, 3600],
    "firedReminderKeys": []
  }]
}
```

`settings.json` 单独存储挂件外观与窗口位置。

写盘策略：临时文件 + 原子 rename + `.bak` 备份，损坏可回滚。

## 五、架构分层

```
commonMain
├── model/        数据模型（持久化与运行时）
├── core/time/    倒计时核心算法与心跳（纯函数，可单测）
├── data/         Repository + JsonCodec（expect 平台 IO）
├── domain/       UseCases（增删改查 / 提醒扫描）
├── ui/theme/     Material3 主题
├── ui/widget/    挂件界面
├── ui/manager/   管理界面
├── ui/settings/  设置界面
└── ui/components/ 通用组件

jvmMain
├── main.kt              application{} 多窗口 + Tray
└── platform/            APPDATA / 文件IO / 自启 / 托盘 / 提醒 / 鼠标穿透
```

## 六、实施阶段

| 阶段 | 内容 | 验收 |
|---|---|---|
| 1 | 项目骨架 + 倒计时核心算法 + 单测 + 最小窗口 | `./gradlew test` 通过，`run` 可启动且秒数跳动 |
| 2 | JSON 持久化 + Repository + 设置（原子写/bak） | 重启后数据不丢，损坏可回滚 |
| 3 | 管理主窗口：列表 + 增改删 + 日期时间选择器 | 添加"期末考试 2027-06-07 09:00"成功 |
| 4 | 挂件窗口：无边框/透明/置顶/拖动/位置记忆/两种尺寸 | 挂件常驻桌面并正确跳动 |
| 5 | 托盘 + 开机自启 + 到期提醒（跨越检测 + 弹窗 + 声音） | 手动改系统时间验证不漏提醒 |
| 6 | 外观自定义 + 鼠标穿透(JNA) + 导入导出 | 穿透生效、配置持久化 |
| 7 | GitHub Actions（windows-latest → MSI/EXE） | tag 触发产出安装包 |

每阶段完成更新 `CHANGELOG.md`。

## 七、风险与对策

1. **mac 打不出 Windows 包** → 本地只调试，CI 产出
2. **未签名被 SmartScreen 拦** → README 注明，后续加证书
3. **透明窗口被全屏遮挡** → 托盘"重新置顶"
4. **JNA native 打包** → Compose Desktop 默认打依赖 jar，JNA 自带 native
